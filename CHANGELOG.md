# Changelog

## 1.2.2

- Allow a nailed controller panel anywhere on its boat to register and pair with an available propeller on the same boat, without requiring hull contact.
- Allow the hammer to nail an onboard panel before the panel has a registered mod mount.
- Reuse existing boat binding, pairing, and persistence. No save format or asset bundle changes.

## 1.2.1 source baseline

The 1.2.2 source is based on the installed 1.2.1 assembly. The previously published repository source described 1.1.0; see `RECONSTRUCTION_NOTES.md` for the source recovery and comparison.
