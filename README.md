# Propeller
Astonding technology breakthrough from Al'Ankh Academy!

## Propeller and control panel
- Both item are now sold at Al'Ankh Academy vendor. It's VERY expensive.
- Attach the propeller and control panel to the postion of your liking, then hammer it to install. Before hammered it won't be able to work.
  - Control panel will automatically pair with the propeller installed after hammered.
  - If you reuse the propeller on other boat, after you hammer the control panel and try to switch it on, there will be a small window to comfrim your current propeller pairing.
- Position of where propeller attached matter! It will create torque depend on where you install it on hull.
  - Vanilla ship's Center of Mass is usually at the keel, so lower the propeller, more stable it will be.
  - You can use this to create turning force, lifting force or diving force.
  - It's possible to make air ship if you place and control the propeller correctly.
- Control panel got following function:
  - Power switch: On/off
  - Water Switch: Water/Air
    - It control if propeller need to be submerged in water to produce propulsion. If switch to Air it will work everywhere, even submerged.
  - Engine Power: 5-100. Use the arrow below to control the power.
  - Wheel Control: after click, make wheel control this propeller's throttle
  - Throttle meter: Show current throttle. Press W/S while holding wheel to increase/decrease throttle.
